# Ginnela - Startup Website

## 🚀 Features

- **Stunning Animated Background**: FloatingLines component with interactive WebGL visualization
- **Modern React Stack**: Built with React 18 + Vite
- **3D Graphics**: Three.js powered shader animations
- **Interactive Effects**: Mouse tracking and parallax effects
- **Responsive Design**: Mobile-friendly layout
- **Custom Gradients**: Easily customize colors and animation parameters

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🎨 Customization

Edit the `FloatingLines` props in `src/App.jsx` to customize:

- `linesGradient`: Array of color hex codes
- `lineCount`: Number of lines per wave layer
- `lineDistance`: Spacing between lines
- `bendRadius`: Mouse interaction radius
- `bendStrength`: Intensity of mouse interaction
- `animationSpeed`: Speed multiplier for waves
- `parallaxStrength`: Strength of parallax effect
